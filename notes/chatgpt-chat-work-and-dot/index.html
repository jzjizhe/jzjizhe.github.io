OpenAI’s ChatGPT has evolved beyond a conversational AI assistant. It now offers three distinct experiences: Chat, Work, and Dot, each designed for a different way of interacting with AI.

At a high level:

  • Chat: Think with AI.
  • Work: Delegate tasks to AI.
  • Dot: Pursue long-term goals with AI.

These experiences illustrate a broader evolution in AI systems: from answering questions, to executing tasks, to pursuing ongoing objectives.

These distinctions are conceptual rather than absolute. Chat can perform sophisticated research, Work can execute recurring tasks, and Dot can answer ordinary questions.

The central difference is how responsibility is organized between the user and the AI system.

A simple analogy:

  • Chat is a consultant: You ask questions and discuss possible solutions.
  • Work is a contractor: You assign a task and receive a deliverable.
  • Dot is a long-term collaborator: You establish a goal and work together toward it over time.

2. ChatGPT Chat: Conversational AI Assistant

Chat is the traditional ChatGPT experience, designed for interactive conversations, knowledge exploration, and problem-solving.

Its primary interaction pattern is user-driven: the user asks a question or provides an instruction, and the model generates a response.

Core Capabilities

  • Conversational reasoning: Answer questions, explain concepts, solve problems, and discuss complex ideas.
  • Web search: Retrieve recent information and incorporate external sources.
  • Multimodal interaction: Understand images, documents, and audio, and generate supported media.
  • File and data analysis: Analyze uploaded documents, datasets, and code.
  • Memory and Projects: Retain relevant context and organize conversations around ongoing topics.
  • Tool integration: Use supported tools and connected applications.

Chat also supports scheduled tasks through ChatGPT’s broader task system, so it is not strictly limited to immediate responses.

Example: AI Research Discussion

Suppose a researcher is exploring world models for computer-use agents.

They might ask:

What are the main challenges in combining world models with computer-use agents? How could a world model improve observation efficiency and action planning?

Chat can explain relevant concepts, review research ideas, formulate hypotheses, and help design experiments.

The interaction is primarily collaborative: the researcher drives the conversation, while Chat provides reasoning and assistance.

Key characteristic: Chat emphasizes interactive intelligence and user-directed exploration.

3. ChatGPT Work: Task-Execution Agent

Work is an agentic environment designed to execute complex, multi-step tasks and produce finished deliverables.

Unlike Chat, which primarily provides conversational assistance, Work can take responsibility for completing a delegated workflow.

Core Capabilities

1. Computer Use

Work can operate a cloud-based computer, interact with websites, and perform supported actions through a browser.

In supported desktop configurations, it can also work with authorized local files and applications.

2. Multi-Step Task Execution

Work can break down a complex objective into smaller steps, execute them, evaluate intermediate results, and adjust its approach.

3. Research and Artifact Creation

Work can produce deliverables such as:

  • Research reports and literature reviews.
  • Documents and presentations.
  • Spreadsheets and data analyses.
  • Websites and other supported project artifacts.

4. Tool and Application Integration

Work can interact with connected applications to retrieve information and perform authorized operations.

5. Background and Scheduled Tasks

Work can continue executing cloud tasks after the user leaves the conversation. It can also run recurring workflows through supported scheduling capabilities.

Example: Automated Literature Review

A researcher could assign Work the following task:

Survey recent papers on world models for computer-use agents. Collect relevant papers, compare their methodologies, datasets, and evaluation metrics, and generate a structured literature review with citations.

Work could search for papers, organize information, compare methods, and prepare the final document.

Instead of guiding every intermediate step, the researcher delegates the objective and reviews the result.

Key characteristic: Work emphasizes delegated execution and concrete deliverables.

4. ChatGPT Dot: Persistent Autonomous Agent

OpenAI introduced Dot on September 29, 2026, as an always-on AI agent designed to take responsibility for ongoing work.

Powered by GPT-6 Astra, a Dot has its own cloud computer, can connect to external applications, and can use memory to maintain context over time.

While Work emphasizes task completion, Dot is designed to support the continuous pursuit of longer-term objectives.

Core Capabilities

1. Persistent Operation

A Dot can maintain responsibilities across conversations and continue making progress on an ongoing project.

2. Long-Term Memory

Dots can use ChatGPT Memory and develop additional memories from interactions, feedback, and connected applications.

3. Proactive Assistance

A Dot can investigate relevant information, identify useful next steps, and suggest actions without waiting for a new explicit user request.

4. Dedicated Cloud Computer

Each Dot has its own cloud computing environment. With permission, it can also access a connected local computer or initiate supported Work and Codex tasks.

5. Cross-Application Workflows

Dots can interact with connected applications through plugins, allowing them to operate across different services.

6. Configurable Autonomy

Users can define which actions a Dot may perform independently and which require approval.

Example: Persistent AI Research Assistant

Consider an ongoing research project on World Models for Agent Self-Improvement.

A researcher could give a Dot the following objective:

Help me continuously advance my research on world models for agent self-improvement. Track relevant papers, maintain research notes, identify promising experimental directions, and suggest the next steps. Ask for approval before making significant changes.

Depending on available tools and permissions, the Dot could periodically review the literature, organize findings, propose experiments, prepare analyses, and request feedback.

Unlike a single Work task, the objective does not necessarily terminate after producing one report.

Key characteristic: Dot emphasizes persistent context, proactive assistance, and long-term responsibility.
